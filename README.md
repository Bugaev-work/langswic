# langswic

<img src="assets/langswic.png" alt="langswic" width="96" />

Локальный переключатель русской и английской раскладки для Windows. Исправляет ошибочный ввод, поддерживает ручное преобразование текста и пользовательские словари. Работает без аккаунта, подписки и передачи набираемого текста в сеть.

**[Скачать установщик для Windows](https://github.com/Bugaev-work/langswic/releases/latest/download/langswic-Setup.exe)** · [Последний выпуск](https://github.com/Bugaev-work/langswic/releases/latest) · [Инструкция по установке](INSTALL.md)

## Возможности

- Автоматическая коррекция раскладки по словарям, включая однозначные начала слов.
- Преобразование последнего слова и выделения, отмена последнего исправления.
- Исправление словарных опечаток, регистра и однозначных форм с «ё».
- Исключения для слов и приложений, отдельное управление видами коррекции.
- Локальное обучение, редактируемые словари, импорт и экспорт настроек.
- Настраиваемые горячие клавиши и звуки, автозапуск, меню в трее.
- Светлая и тёмная темы, управление интерфейсом с клавиатуры.

Подробный статус функций и способы проверки приведены в [FEATURES.md](FEATURES.md).

## Требования

Windows 10/11 x64, .NET Framework 4.8, установленные раскладки Russian и English (United States). Системные словари Windows расширяют распознавание; встроенные и пользовательские словари доступны независимо от них.

## Установка

Текущая версия: **1.5.3**. Готовый установщик и контрольная сумма SHA-256 доступны в [GitHub Releases](https://github.com/Bugaev-work/langswic/releases/latest). Для установки компилятор и исходный код не требуются.

1. [Скачайте `langswic-Setup.exe`](https://github.com/Bugaev-work/langswic/releases/latest/download/langswic-Setup.exe) и запустите его.
2. Запустите **langswic** из меню «Пуск».
3. Настройте автоматику и горячие клавиши. Автозапуск включается в настройках или меню трея.

Установка выполняется для текущего пользователя без прав администратора. Файлы программы находятся в `%LOCALAPPDATA%\Programs\langswic`. Настройки и словари хранятся в `%LOCALAPPDATA%\langswic`.

Подробности установки, обновления и проверки файла — в [INSTALL.md](INSTALL.md). Установщик пока не имеет цифровой подписи; Windows может показать предупреждение о неизвестном издателе.

## Управление

| Команда по умолчанию | Действие |
| --- | --- |
| Single Shift | Сменить RU/EN, в том числе без набора текста |
| Double Shift / Pause | Отменить доступное исправление или преобразовать слово/выделение; Double Shift без текста меняет раскладку |
| Ctrl+Alt+F9 | Преобразовать слово у курсора |
| Ctrl+Alt+F12 | Преобразовать выделенный текст |
| Ctrl+Alt+F11 | Отменить последнее исправление |
| Ctrl+Alt+F10 | Включить или выключить автоматику |

Single Shift ожидает 470 мс после отпускания, чтобы отличить одиночное нажатие от Double Shift. Сочетания и обработку Shift можно изменить на странице «Горячие клавиши».

Закрытие окна оставляет программу в трее. Для завершения выберите «Выйти из langswic» в меню значка.

## Сборка и проверки

В PowerShell из корня проекта:

```powershell
# Первичная подготовка компилятора нативного модуля
powershell -NoProfile -ExecutionPolicy Bypass -File .\native\bootstrap.ps1

# Сборка, автоматические проверки и установочный пакет
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Первичная подготовка загружает Zig 0.14.1 с официального сайта и проверяет закреплённую SHA-256. Последующие сборки выполняются без сети. C# компилируется системным компилятором .NET Framework; нативный модуль встраивается в EXE. Режим `build.ps1 -CompileOnly` пропускает проверки и создание установщика.

Проверки охватывают логику коррекции, страницы интерфейса в обеих темах, меню трея и ввод в отдельных тестовых окнах Win32/UI Automation. Архитектура описана в [ARCHITECTURE.md](ARCHITECTURE.md), сценарии и статус проверки приложений — в [MANUAL_TESTS.md](MANUAL_TESTS.md).

Для сопровождающего проекта: после проверки пакета, обновления RELEASE_NOTES.md, коммита и отправки исходников `release.ps1 -Version 1.5.3` создаёт черновик GitHub Release и проверяет контрольные суммы загруженных файлов. Ключ `-Publish` публикует выпуск. Используется существующая авторизация Git; в репозиторий токены не записываются.

## Совместимость и данные

Для коррекции нужен доступный редактируемый элемент с достоверным курсором или выделением. Поля паролей, неизвестные поля и непроверяемые диапазоны пропускаются. Журнал нажатий клавиш не ведётся. Неизвестные обоим словарям слова сохраняются.

По умолчанию автоматика отключена в терминалах, средах разработки и удалённых сеансах. Защищённые и 32-разрядные приложения могут отклонять смену раскладки. Совместимость с конкретными версиями Chrome и ChatGPT требует ручного подтверждения; автоматические тесты механизмов Windows не заменяют эту проверку.

## Удаление

Удалите **langswic** через «Параметры → Приложения». Программа, ярлык и автозапуск будут удалены. Пользовательские настройки сохраняются; папку `%LOCALAPPDATA%\langswic` можно удалить вручную после экспорта нужных данных.
