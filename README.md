# Fast Switcher

Локальный переключатель раскладки RU/EN и корректор для Windows 10/11 x64. Это самостоятельный проект для личного пользования, без аккаунта, подписки и сетевого обмена набираемым текстом. Функции и проверенные границы описаны в [FEATURES.md](FEATURES.md).

## Установка

Репозиторий содержит исходники. Сначала выполните сборку по разделу «Сборка из исходников»: она создаст установщик в `dist`. Готовые EXE и машинные отчёты в Git не включаются.

1. Запустите [FastSwitcher-Setup.exe](dist/FastSwitcher-Setup.exe). Администратор не требуется.
2. Установщик скопирует EXE в `%LOCALAPPDATA%\Programs\FastSwitcher`, создаст ярлык «Fast Switcher» в меню «Пуск» и запись в «Установленных приложениях».
3. Запустите «Fast Switcher» через меню «Пуск». В трее появится оранжевая иконка «F». При первом запуске проверьте, что установлены раскладки English (United States) и Russian. При обновлении прежняя установка «Ладо» удаляется, а её настройки переносятся в новый профиль; исходная копия данных остаётся в `%LOCALAPPDATA%\Lado`.
4. Автозапуск включается на экране «Настройки». Для корректной работы нельзя одновременно запускать другой автопереключатель раскладки.

Системное требование: .NET Framework 4.8, обычный пользовательский интерактивный сеанс Windows. Программа x64 и работает офлайн. Установочный EXE — тот же однопакетный исполняемый файл с режимом установки. Контрольная сумма SHA-256 выводится `build.ps1`.

## Использование

В обновлении **1.4.1** исправлен путь замены слова у курсора: проверенный текст удаляется и вставляется одной очередью ввода без промежуточного выделения через UI Automation. После преобразования назначается язык нового текста; запрос получают поле и верхнее окно приложения, а фактический HKL проверяется повторно. Неподтверждённая смена языка видна в «Диагностике». Приложение может отклонить системный запрос — совместимость с конкретной версией Chrome или настольного ChatGPT пока не подтверждена.

- Автосмена раскладки происходит, если исходное слово не распознано, а преобразованный вариант распознан. Если оба варианта неизвестны, раскладка и слово не меняются. Учитываются встроенные, пользовательские и установленные словари Windows RU/EN; доступность последних видна в «Диагностике». На этом ПК доступны оба системных словаря. Программа не скачивает словари; без языкового компонента Windows соответствующий язык проверяется только по встроенному и пользовательскому спискам.
- Наберите `ghbdtn ` в английской раскладке: словарное слово должно стать `привет `. `руддщ ` в русской раскладке должно стать `hello `.
- В русской раскладке начните набирать `пщмуктьуте`: уже после `пщмук` однозначное начало должно стать `gover`, а законченное слово — `government` без пробела. При неоднозначном начале программа оставляет ввод до проверки целого слова.
- В поисковом поле браузера проверьте `ghbdtn ` → `привет `. Программа обрабатывает доступные редактируемые поля Edit/ComboBox/Document и Custom с подтверждённым TextPattern, включая вложенные элементы. Для UI Automation требуется доступный текст и точный диапазон курсора/выделения. Замена подтверждается до ввода и после него; всё поле через Ctrl+A не переписывается.
- Этот способ применяется и к обычным текстовым полям других приложений. Чтение поля выполняется на отдельном потоке и не задерживает перехват клавиатуры. Короткие повторные проверки компенсируют задержки UI Automation; новый ввод или смена фокуса отменяют ожидающую замену.
- Double Shift и Pause/Break преобразуют выделенный текст, а без выделения — слово непосредственно перед курсором. Если последнее исправление ещё можно отменить, повторное нажатие возвращает исходный текст. `Ctrl+Alt+F11` отменяет последнюю операцию, `Ctrl+Alt+F12` преобразует выделение, `Ctrl+Alt+F9` работает со словом у курсора.
- В редакторах UI Automation выделение после преобразования снимается и курсор остаётся в конце вставленного текста. Если невозможно точно проверить выбранный текст или слово у курсора, ручная замена пропускается. Double Shift берёт текущее выделение или слово, если прежнее исправление уже нельзя отменить. Поля только с ValuePattern, без доступа к курсору через TextPattern, пропускаются.
- `Ctrl+Alt+F10` включает и выключает автоматику. Все сочетания можно поменять на экране «Горячие клавиши»; конфликт Windows показывается там же.
- Исключения процессов и слов, пользовательские словари и выученные правила редактируются в отдельных разделах. Настройки экспортируются в JSON.
- Закрытие окна оставляет программу в трее; команда «Выход» завершает её.

По умолчанию автоматика отключена для `devenv`, `code`, `rider64`, `idea64`, `pycharm64`, `windowsterminal`, `wt`, `cmd`, `powershell`, `pwsh`, `conhost` и `mstsc`. Новые исключения добавляются по имени процесса без `.exe`. Поля паролей и поля неизвестного типа пропускаются.

Ранняя коррекция использует однозначные префиксы встроенного и пользовательского словарей. Проверка Windows определяет целые слова, поэтому для слов вне этих списков раннее исправление возможно после распознавания полного слова, ещё до пробела. Из неполного слова нельзя достоверно узнать будущий текст: начало неизвестного имени или адреса иногда совпадает со знакомым словом. Такие слова можно добавить в исключения.

## Удаление

Удалите «Fast Switcher» через «Параметры → Приложения → Установленные приложения». Программа, ярлык и запись автозапуска удаляются. Личные настройки остаются в `%LOCALAPPDATA%\FastSwitcher`; при желании удалите эту папку вручную после экспорта нужных словарей.

## Сборка из исходников

Откройте PowerShell в каталоге проекта и выполните `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`. Скрипт создаёт оригинальную иконку, компилирует EXE системным `csc.exe`, запускает тесты ядра, шести экранов и ввода в отдельное тестовое окно, затем создаёт `dist\FastSwitcher-Setup.exe`, `dist\ui-preview.png` и `dist\SHA256SUMS.txt`. Интернет и внешние пакеты не нужны. Тесты можно повторить командами `dist\FastSwitcher.Tests.exe --self-test`, `--smoke-test` и `--input-test`.

`-CompileOnly` только компилирует исходники; не запускает окна и не обновляет установщик. Проверка ввода использует временные окна и синтетические строки, а не пользовательские тексты. Проверяются также защищённое поле, редактор Document без ValuePattern и продолжение работы после задержки чтения поля.

## Проверка на живых приложениях

Сценарий и текущий статус — в [MANUAL_TESTS.md](MANUAL_TESTS.md). Реальный ввод в разных приложениях зависит от их поддержки UI Automation и Win32; результаты до ручной проверки не заявляются как подтверждённые.

Для проверки обычного поиска, textarea, contenteditable и защищённого поля откройте [compatibility.html](compatibility.html) в Chrome. Это локальная страница без скриптов и отправки форм. Её создание не означает, что проверка в самом Chrome уже выполнена.
