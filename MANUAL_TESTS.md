# Сценарий проверки в приложениях

Результаты сборки **1.4.1** от 1 октября 2026 года: **34 проверки ядра пройдены, 0 ошибок**. Пройдены smoke-тест шести экранов и клавиатурного хука и весь интеграционный тест системного ввода. Проверялись отдельные реальные окна Win32 Edit, WPF Edit, форматированный Document без ValuePattern и редактируемый Custom с TextPattern. Это проверки механизмов Windows, а не доказательство работы в продуктах Chrome или ChatGPT. Локальный вывод сборки сохранён в `dist/build-verification.txt`.

Новые регрессии: дочерний HWND игнорирует смену языка, а верхний HWND принимает её — после RU-конвертации язык остаётся RU, после раннего `пщмук` → `gover` остаётся EN. UIA-провайдер Custom намеренно переносит курсор в начало документа при Select; преобразование всё равно проходит без вызова Select. После `KEEP ghbdtn tail` → `KEEP привет tail` следующая клавиша F даёт `KEEP привета tail`, без потери соседних букв. Проверены повторная конвертация и продолжение раннего слова при задержке проверки результата.

Проверены RU→EN, EN→RU, ранняя коррекция `пщмук` → `gover`, дописывание `government`, отмена, Double Shift с выделением и без него; полное и частичное выделение `привет how are`; автоисправление `recieve ` → `receive `; сохранение соседних букв при изменении поля; повторяющиеся слова; неизвестное слово без замены; словарь Windows вне встроенного списка. Защищённое поле пропускает и автоматику, и Double Shift. В Document замена `KEEP ghbdtn tail` → `KEEP привет tail` сохранила соседние слова и жирное начертание KEEP.

Дополнительно пройдены два сценария задержек: обработчик ввода сохранил работоспособность при задержке текстового потока 1600 мс; при задержке проверки вставки 500 мс пользовательский ввод продолжился до `government `, после чего Double Shift вернул целое исходное `пщмуктьуте `. В тестовом сценарии исправлен порядок ожидания: перед новым действием проверяется готовность курсора/операции, а не только появление символов в поле.

Установщик 1.4.1 завершился с кодом 0, запись удаления показывает 1.4.1, установленный EXE совпадает с пакетом по SHA-256: `1F56E63E7501C206824BFFAD9844C6D75E9835CAE4341B922F646C670F2481A5`. Программа запущена из `%LOCALAPPDATA%\\Programs\\FastSwitcher`. Машинный отчёт установки создаётся локально в `dist/install-verification.txt` и не включается в репозиторий.

Живая проверка Chrome для 1.4.1 снова была технически остановлена Computer Use: инструмент не смог определить текущий URL для проверки политики доступа и прекратил управление браузером в этом ходе. Навык computer-use и его правила запрещают автоматизацию UI настольного ChatGPT. Эти проверки не объявляются пройденными. Для дальнейшей проверки браузера подготовлена [локальная страница с input, textarea и contenteditable](compatibility.html), без скриптов и сети.

Прежний отказ доступа к Блокноту позже не воспроизвёлся: Computer Use запустил Блокнот, ввёл служебную строку и прочитал её, но захват изображения завершался тайм-аутом.
