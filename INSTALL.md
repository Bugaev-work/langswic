# Установка langswic

## Скачать

Откройте [последний выпуск](https://github.com/Bugaev-work/langswic/releases/latest) и скачайте **langswic-Setup.exe** из раздела Assets. Можно использовать [прямую ссылку на установщик](https://github.com/Bugaev-work/langswic/releases/latest/download/langswic-Setup.exe).

Для работы нужны Windows 10/11 **x64**, .NET Framework 4.8 и раскладки **Russian** и **English (United States)**. На компьютерах с другой архитектурой этот пакет не поддерживается.

Установщик содержит готовую программу. Скачивать исходный код, устанавливать компилятор или выполнять команды сборки не нужно.

## Проверка файла

Установщик пока не подписан цифровым сертификатом. Windows может показать предупреждение о неизвестном издателе. Перед запуском проверьте, что файл скачан из репозитория `Bugaev-work/langswic`.

В Assets также находится **SHA256SUMS.txt**. Для сверки файла в PowerShell выполните команду, указав путь к скачанному установщику:

```powershell
Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\langswic-Setup.exe" -Algorithm SHA256
```

Значение Hash должно совпасть со строкой `langswic-Setup.exe` в файле SHA256SUMS.txt того же выпуска.

## Установить

1. Запустите **langswic-Setup.exe** двойным щелчком.
2. Дождитесь сообщения об успешной установке. Права администратора не требуются.
3. Программа запустится; её ярлык появится в меню «Пуск», а значок — в системном трее. Двойной щелчок по значку открывает окно настроек.
4. Проверьте наличие русской и английской раскладок. Автоматику, горячие клавиши и исключения настройте под свои приложения. Автозапуск включается в настройках или меню трея.

Программа работает локально без аккаунта и подключения к сети. На каждом компьютере создаются собственные настройки и словари.

## Быстрая проверка

В обычном текстовом поле наберите `ghbdtn` в английской раскладке: при распознавании слово исправляется на `привет`, язык должен остаться русским. Double Shift отменяет доступное исправление или преобразует слово/выделение; в пустом поле переключает раскладку. Single Shift меняет язык после задержки распознавания Double Shift.

Для работы автоматики исходное слово должно быть неизвестным, а преобразованный вариант — словарным. Неизвестные обоим словарям слова сохраняются. Совместимость зависит от доступности поля ввода; в терминалах, средах разработки и удалённых сеансах автоматика по умолчанию отключена. Подробности: [возможности](FEATURES.md) и [статус проверок](MANUAL_TESTS.md).

## Обновить

Скачайте установщик нового выпуска и запустите его. Установленная программа будет заменена, настройки и пользовательские словари сохранятся. По завершении запустится новая версия.

## Удалить

Откройте «Параметры → Приложения», найдите **langswic** и выберите «Удалить». Программа, ярлык и автозапуск будут удалены.

Пользовательские данные остаются в `%LOCALAPPDATA%\langswic`. При необходимости сначала экспортируйте их в настройках, затем удалите эту папку вручную.
