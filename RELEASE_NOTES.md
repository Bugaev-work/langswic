# langswic 1.5.4 — Windows x64

Готовый установщик для Windows 10/11 x64. Программа работает локально без аккаунта, подписки и передачи набираемого текста в сеть.

## Установка

1. Скачайте **langswic-Setup.exe** из Assets ниже и запустите его.
2. Дождитесь сообщения об успешной установке. Права администратора не нужны.
3. Откройте langswic из меню «Пуск» или значка в трее.

Нужны .NET Framework 4.8 и раскладки Russian / English (United States). Компилятор и исходный код для установки не требуются. Инструкция приложена в **INSTALL.md**.

## Изменения

- Убраны рамки кнопок после щелчка; для клавиатурной навигации сохранён компактный маркер.
- Удалён раздел «Словари». Ранее сохранённые слова и выученные правила остаются в пользовательских данных и экспорте JSON.
- Таблица исключений заменена списком программ. EXE выбирается через Проводник, изменения сохраняются сразу.
- Для каждой программы отдельно разрешаются раскладка, опечатки и ё. Новое исключение отключает все виды автоматики; дубликаты не создаются.

## Проверки и ограничения

Пройдены 51 проверка ядра, все четыре страницы и восемь категорий в обеих темах, проверки добавления/сохранения/удаления исключений и все интеграционные проверки системного ввода в отдельных окнах Win32/UI Automation. Проверены сохранение языка, Double Shift, ранняя коррекция, курсор, соседний текст и защищённое поле.

Совместимость с конкретными версиями Chrome и ChatGPT требует ручного подтверждения. Исключения применяются по имени процесса ко всем экземплярам выбранной программы.

Установщик пока не имеет цифровой подписи. Windows может показать предупреждение об неизвестном издателе. Для сверки скачанного файла используйте **SHA256SUMS.txt** этого выпуска.
