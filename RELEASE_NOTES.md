# langswic 1.5.3 — Windows x64

Готовый установщик для Windows 10/11 x64. Программа работает локально без аккаунта, подписки и передачи набираемого текста в сеть.

## Установка

1. Скачайте **langswic-Setup.exe** из Assets ниже.
2. Запустите файл и дождитесь сообщения об успешной установке. Права администратора не нужны.
3. Откройте langswic из меню «Пуск» или двойным щелчком по значку в трее.

Нужны .NET Framework 4.8 и раскладки Russian / English (United States). Компилятор и исходный код для установки не требуются. Подробная инструкция приложена в **INSTALL.md**.

## Изменения

- Единое оформление переключателей, категорий, полей ввода, таблицы исключений и прокрутки.
- Светлая и тёмная темы, подсветка фокуса, управление с клавиатуры.
- Официальное описание проекта и инструкции для установки на другом компьютере.

## Проверки и ограничения

Пройдены 51 проверка ядра, проверки всех страниц в обеих темах и взаимодействия с новыми элементами интерфейса. Установленная копия совпадает с пакетом по SHA-256.

Повторный интеграционный тест ввода 1.5.3 остановился до отправки клавиш: Windows отказала тестовому окну в активации. Его успешное прохождение не заявляется. Механизмы ввода не изменены по сравнению с ранее проверенной 1.5.2. Совместимость с конкретными версиями Chrome и ChatGPT требует ручного подтверждения; доступность редактируемого поля влияет на работу коррекции.

Установщик пока не имеет цифровой подписи. Windows может показать предупреждение об неизвестном издателе. Для проверки скачанного файла используйте **SHA256SUMS.txt** из этого же выпуска.
