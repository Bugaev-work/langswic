# Project instructions

The user requests that every completed version of langswic be committed and pushed to GitHub. After completing and validating a version, create a descriptive commit and push it to the configured origin branch. This authorization applies to release work in this project.

Keep user settings, personal dictionaries, credentials and local verification artifacts out of Git. Build artifacts remain ignored. Preserve the original, offline design and protected input safeguards.

Installer distribution uses GitHub Releases. Keep README download links pointing to the latest release. For a completed application version, publish the matching installer, SHA256SUMS.txt and INSTALL.md using release.ps1 after verifying the package and pushing the source commit. Release notes must report actual checks and limitations. Do not replace files in a published version; create a new version instead.
